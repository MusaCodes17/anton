## 1. Sixty-Second Summary

Anton (repo `anton`, renamed from `running-shoe-deals` on 2026-07-14) is a **single-user personal running platform**: shoe-deal watching across 8 Canadian retailers + a canonical run/training history + shoe rotation wear tracking, with an embedded AI assistant (Son of Anton) and a full MCP server used by Claude Desktop. FastAPI + SQLite + React SPA. Deployed on a Hetzner host (`anton.musasouled.com`, Caddy + Docker, single Uvicorn worker) and installable as a PWA; protected by bearer-secret + OAuth 2.1 (R2.1 → E9/E10) with Litestream backups to B2.

**Where things stand right now (2026-10-10):** the platform is built. The redesign (five tabs), all of R2, R3.1–R3.4 + R3.6, R4.1/R4.2/R4.4/R4.6, the RA1 remote-access milestone (cutover closed 2026-08-29), RA2.2 PWA, R5.7 COROS direct sync, **R6** (daily-use improvements; R6.4 paused: measured once and not built, see below), **R7** (polish & coverage) and **R8** (Training page: Race PBs + Best efforts on elapsed time, segment best efforts, past-race actions, automatic fitness snapshots, and the "Now" strip) are shipped. R3.5 (push notifications) stays deferred: R6.4's step 0 found no need on a sample of one run, and it is re-measured after a few weeks of real use before being closed for good (roadmap §R6.4).
